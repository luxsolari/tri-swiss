06 — Governance

Highlight

Pastel Turquoise is not a second accent. It carries zero semantic meaning: never success, never info, never a second interactive state. Unlike Swiss Red, it is never the answer when an element needs to signal something. It is sanctioned for open-ended decorative reuse, and it has a Structural Block of its own.

Sanctioned uses

  1. 01A second data series in a hand-rolled SVG or Observable Plot chart, when it is a genuine third line and solid-versus-dashed is exhausted.
  2. 02A brand or hero moment: the hero's turquoise line and its filled circle icon.
  3. 03An icon fill on a single icon, as a flourish rather than a state cue.
  4. 04An underline or rule beneath a heading or label, 2px.
  5. 05A background wash at 10% behind a block that wants separation without a hard border.
  6. 06A dot accent, matching the dot-indicator pattern.
  7. 07A hover-triggered flourish on a nav link or label: an underline that appears on hover, identical regardless of state, layered alongside the element's real feedback.
  8. 08A card's border plus a subtle 8% wash: the Accent card.
  9. 09Its own Structural Block: the callout panel, the second-moment panel, the closing band.

It can recur multiple times on the same page; the old one-brand-moment cap is gone. The test that governs every use is unchanged: if Turquoise's presence or absence would change what the reader understands about state, it is wrong. If it is purely ornamental and removable without changing meaning, it is fine.

A genuine third color.
Underline Wash at 10%

Never

  • As a button's, tag's, status pip's or link's own state-indicating or rest color.
  • Adjacent to Red on the same element, except inside the tri-part stripe.
  • On a list marker or table rule.
  • As text carrying meaning on the cream ground: at 1.95:1 it is decoration only.

The dual-accent exception

The Accent button and the Interactive card swap Red for Turquoise on hover: red border at rest, turquoise fill or border on hover. This is a genuine, deliberate exception to "Red is the only color permitted to carry real hover meaning," scoped to exactly these two patterns. The two colors are never visible on the element simultaneously, so it does not touch the never-adjacent guardrail. It must not spread beyond these two.

Turquoise's Structural Block

Parallel to Red's block but kept clearly secondary. Never adjacent to Red's Sidebar or HeroBand; combined footprint visibly smaller than Red's wherever both appear; ink and cream still dominate every surface outside these blocks; one accent per component still holds. highlight-foreground is constant black on these fills in both themes.

Callout panel

Solid highlight, padding 14px by 16px, max width 60ch. Content-sized, never full-bleed; may recur a few times per page.

Note

A content-level device, not page chrome. Title at 0.7rem mono 700, body at 0.9rem.
