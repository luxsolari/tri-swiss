Button

Five variants in the uppercase mono label style, mono 0.75rem, uppercase, 0.2em tracking, padding space-2 by space-4, square corners.

Default
Hover
  • Ghost / nav (most common): no border, muted-foreground, foreground on hover.
  • Outlined: 1px foreground border; inverts to a foreground fill on hover.
  • Filled (primary action, rare): foreground fill, background text, 90% on hover.
  • Destructive: 1px primary border and text; fills primary on hover. Red carries the real hover signal.
  • Accent: primary at rest; on hover the border and fill become highlight with highlight-foreground text. The dual-accent exception, scoped to this button and the Interactive card. Red and Turquoise are never visible on it at the same moment.
  • Disabled is always opacity 0.4. Focus is a 1px ring. Turquoise never appears on a button at rest.

Tag

Small inline badges in mono at 0.65rem, uppercase, 0.12em tracking, padding 2px by 8px. Four variants, all ink-only.

Variants
NeutralSignalOutlinedSaved

Neutral is muted-foreground text. Signal inverts to a foreground fill. Outlined is a dashed foreground border at 50% with a 4px dot. Saved is a solid border at 30%, text at 50%, same dot. Never rounded-full, never primary or highlight on a tag.

Emphasis card: the border swaps to primary for one card in a set, the featured, current or first one. Never a whole grid. Accent card: highlight border and an 8% wash. Stronger than Emphasis and non-semantic. Interactive card: wrap in <a> or <button>; primary border at rest, highlight border and a 5% wash on hover. The dual-accent exception applied to a card.

Input

A text field on the input surface with a 1px border, padding space-2 by space-3, mono text at 0.85rem. Focus is a 1px ring, Swiss Red.

The label above is the uppercase mono label, foreground and 700 when active. Square corners, no inner shadow. Errors are copy and weight, not a red field, and never Turquoise.

StatusPip

An inline indicator: a 6px dot and an uppercase mono label at 0.75rem with 0.15em tracking. State lives in the dot alone.

States
ConnectedWarningLoadingDisconnected

Connected is foreground; Warning is primary; Loading is muted-foreground at 30% with a pulse; Disconnected is foreground at 25%. highlight never appears here: a turquoise dot would read as a state.

SegmentStripe

Three equal solid segments, foreground, primary, highlight, 3px tall, as a static decorative divider at any length. The one place the two accents touch.

DecorativeAccent

The small, non-semantic Turquoise touches. Each may recur on a page; none may carry meaning.

Four touches
Icon fillDotUnderlineUnderlined labelWash · 10%Separated without a border

A highlight fill on a single icon as a flourish, a 6px dot, a 2px underline beneath a heading or label, a 10% wash behind a block that wants separation without a hard border. If removing one would change what the reader understands about state, it is the wrong tool. Never on a button, tag, pip or link as its rest color; never adjacent to Red on the same element.

Figure

An image in a 1px border container at a consistent aspect ratio with a mono italic caption beneath a 1px rule. Grayscale by default.

The default is filter: grayscale(1) or a duotone toward ink and cream. Full color is a scoped exception for photography that is itself the content, never decoration in UI chrome. The demo stands in for a photograph with a swatch.

Chart

Hand-rolled SVG in foreground, muted-foreground and primary, with highlight for a genuine third series only. The full treatment is on the Charts page.

Encode categories and emphasis with fill opacity, solid versus dashed strokes and outline rings first; reach for highlight only when those are exhausted and a chart truly needs a third distinct line.

Icon

geist-icons is the single sanctioned icon set: no other library, no icon fonts, no emoji. Restyle its defaults with one CSS rule.

geist-icons, restyled — stroke 1.5, square caps, miter joins
View on GitHub
.icon {{ width: 20px; height: 20px; fill: none; stroke: currentColor;
  stroke-width: 1.5; stroke-linecap: square; stroke-linejoin: miter; }}

Size 16 to 20px, currentColor inheriting foreground or muted-foreground; primary only in the destructive and accent cases already reserved for it; highlight only as a single decorative fill, such as the hero's circle, never a state cue. Icons augment the uppercase mono label and never replace it. In React import from geist-icons and pass the same stroke props.
